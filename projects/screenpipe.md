# Screenpipe: Recall something seen across apps or retrieve meeting context for an assistant

Captures screen text and audio history into a searchable local store, with a desktop timeline, local API and MCP access for assistants.

[Upstream project](https://github.com/screenpipe/screenpipe) · [Back to collection](../README.md#personal-memory)

| Field | Details |
|---|---|
| Category | Personal memory |
| Use case | Recall something seen across apps or retrieve meeting context for an assistant. |
| Requirements | macOS or Windows app, or Linux source build; grant capture permissions. For local AI, configure local transcription and a local model such as Ollama. MCP needs a running Screenpipe instance and the documented local API key. |
| Caveat | Source-available under the Screenpipe Commercial License, not an OSI open-source license. Raw history stays local by default; cloud AI, transcription, sync and integrations can send context off-device. A cloud-connected MCP client may send retrieved history to its model provider. Local models and continuous capture consume machine resources; no hardware benchmark is claimed. |
| Evidence | documentation-reviewed |
| Documentation reviewed | 2026-09-17 |
